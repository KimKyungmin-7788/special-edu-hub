# 연구회게시판 권한 검증 — 2026-10-27

## 검증 방식

연결된 Supabase에서 `tests/research_board_permissions.sql`을 실행했다.
`SET LOCAL ROLE authenticated/anon`과 회원별 JWT sub를 사용하여 실제 RLS 및 RPC를 검사했다.
관리자 계정의 RLS 우회 SELECT만으로 권한을 판정하지 않았다.
등급 부여·회수 및 글·댓글·알림·신고 생성은 한 트랜잭션에서 수행한 뒤 모두 ROLLBACK했다.

## 통과 항목

- 관리자 RPC로 연구회회원 부여·회수 가능
- 일반회원의 등급 부여 RPC 및 profiles 직접 UPDATE 차단
- 연구회회원은 교사인증이 없어도 게시판·글 조회, 글·댓글 작성·수정 가능
- 비회원은 boards/posts/comments 조회 결과에서 연구회 자료를 받지 못함
- 비회원 글·댓글 작성 차단
- 비회원의 댓글 신고를 통한 스냅샷 우회 접근 차단
- 연구회회원이 아닌 관리자도 연구회 글·신고 조회 및 글 삭제 차단
- 등급 회수 후 작성자 본인도 글·댓글·기존 신고·알림 조회 및 댓글 수정 차단
- 비로그인 게시판·글·댓글 조회 차단
- 비회원 멘션 알림 생성 차단
- 회원에게 전달되는 댓글 알림의 board_id·이동 경로 확인
- 연구회게시판 공개 이미지 첨부 거절
- 자유게시판 기존 권한 테스트 16개 묶음 재실행 통과

## 실제 브라우저 확인

로그인된 관리자에게 연구회회원 등급이 없는 상태에서:

- `/board/free`의 하위 메뉴에는 자유게시판만 표시됨
- `/board/research` 직접 접속은 ‘접근 권한이 없습니다’만 표시됨
- 해당 화면에도 연구회 메뉴·목록·제목·글쓰기 버튼이 표시되지 않음

회원 부여 후 메뉴 노출·회수 후 메뉴 제거의 브라우저 전환은 이번 검사에서 실행하지 않았다.
실제 회원 등급을 유지한 채, 부여·회수의 허용/거절과 데이터 접근 변화는 DB 트랜잭션으로 검증했다.

## 정리

- 테스트 연구회 글 0건, 테스트 알림 0건으로 롤백 확인.
- 검사 종료 시 실제 연구회회원 0명. 관리 → 회원 → 연구회회원 ‘부여’로 지정 가능.
- 추가 수정이 필요한 오류는 검증 범위에서 발견되지 않음.
